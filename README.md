# 🎮 Snake, Water, Gun Game

A simple Python command-line game based on the classic **Snake, Water, Gun** concept. The project is designed to practice Python fundamentals, user input, conditional logic, randomization, and game-flow control.

## ✨ Features

- 🎲 Computer makes a random choice
- 👤 Player enters a choice through the terminal
- 🧠 Game logic determines win, lose, or draw
- 🔁 Simple interactive gameplay
- 🐍 Snake vs Water vs Gun rules
- 💻 Beginner-friendly command-line interface

## 🛠️ Tech Stack

- Python
- `random` module
- Command-line interface

## 🎯 Game Rules

| Player | Beats |
|---|---|
| 🐍 Snake | 💧 Water |
| 💧 Water | 🔫 Gun |
| 🔫 Gun | 🐍 Snake |

## 🔄 How It Works

```text
Player Choice
      ↓
Computer Random Choice
      ↓
Compare Choices
      ↓
Determine Result
      ↓
Display Result
```

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/shovan12/Snake-Water-gun-game-project.git
cd Snake-Water-gun-game-project
```

### 2. Run the Python program

```bash
python main.py
```

> If the Python file in the repository has a different filename, run that `.py` file instead.
